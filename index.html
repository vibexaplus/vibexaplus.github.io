How to install
  1. Tap Download and wait for the file to finish.

FAQ

Questions, answered

Is Vibexa Plus free?

Yes. Vibexa Plus is free to download and use, with no ads.

Why isn’t it on the Play Store?

For now, you get Vibexa Plus from this page (the file is published on GitHub Releases). To update, download the newest file and install it; updates install over the old version and keep your library.

Is it safe to install?

Vibexa Plus is signed by the developer, and every update is signed with the same key. Download it only from this page or the project’s GitHub Releases. Android will ask you to allow installs from this source before it installs.

To verify the file yourself, compare its SHA-256 with the checksum in the download section, and check the signing certificate (SHA-256):

13abc99cf838af10e913ae99f360082bd81c5e21a4119be2293e8f33a4fa11f5

For example with apksigner verify --print-certs Vibexa-Plus.apk.

Can I use it on iPhone?

Not right now. Vibexa Plus is an Android app, and iPhone and iPad can’t install APK files. Open this page on an Android phone or tablet to download it.

Which phones does it work on?

64-bit Android phones running Android 8.0 or newer, which covers almost every phone from the last seven years.

Does it work without internet?

Yes. Everything saved on your phone plays without internet. You only need a connection to save something new.

What can I download?

Paste a link from supported sites to save the video or audio, or open a magnet link or torrent file. Only download things you own or have permission to save.

Do you collect my data?

No. Vibexa Plus doesn’t need an account and contains no analytics, ads or crash-reporting services. Nothing is sent to the developer; your videos, music and settings stay on your phone. Read the privacy policy.
